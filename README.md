# 🎧 Cloudbeats

CloudBeats is a modern online radio platform that combines automated music streaming, live broadcasting and a responsive listening experience.

The platform was designed to provide a simple and accessible way for users to listen to curated music playlists through a web browser or mobile application.

Unlike traditional static radio websites, CloudBeats aims to offer a modern streaming experience with real-time information, responsive design and future support for radio administration tools.

The project combines Front-End Development, Cloud Infrastructure and Audio Streaming technologies to create a real-world radio solution.

## UX Design

### User stories

### First Time Visitor

- As a visitor, I want to access the radio from any device so that I can listen wherever I am.

### Listener

- As a listener, I want to play and pause the stream so that I can control my listening experience.
- As a listener, I want to adjust the volume so that I can listen comfortably.
- As a listener, I want to view the current song so that I can discover new music.
- As a listener, I want to know when the station is live so that I understand the current broadcast status.

### Future Administrator

- As a radio administrator, I want to manage playlists so that I can control the station schedule.
- As a radio administrator, I want to switch between automated playlists and live broadcasts so that I can host live events.


### Project Goals

CloudBeats was designed to provide a modern online radio experience that is simple, accessible and enjoyable across multiple devices.

The primary goals of the project are:

- Deliver uninterrupted music streaming.
- Provide an intuitive listening experience.
- Support both automated playlists and live broadcasts.
- Ensure accessibility across desktop, tablet and mobile devices.
- Create a scalable foundation for future radio management features.

### Target Audience

CloudBeats is designed for users who enjoy listening to curated music playlists through an online radio platform.

The target audience includes:

- Casual listeners looking for background music.
- Users who enjoy discovering new songs and artists.
- Mobile users who listen while travelling.
- Desktop users listening while working or studying.
- Future radio administrators who will manage playlists and broadcasts.

The platform aims to provide a simple and distraction-free listening experience for all users regardless of their technical knowledge.


### Design Principles

The interface was designed following modern UX principles:

- Simplicity
- Consistency
- Accessibility
- User Control
- Responsive Design

### Simpllicity

The interface was designed to provide immediate access to the radio stream with minimal user interaction.

#### Consistency

Consistent colours, typography and spacing are used throughout the interface to create a predictable user experience.

#### Accessibility

High contrast colours and responsive layouts were used to improve readability and usability.


### User Control

Users have full control over audio playback through:

- Play / Pause button
- Volume control
- Progress information
- Live status indicator


### Responsive Design

CloudBeats was developed using a responsive layout to ensure a consistent user experience across different screen sizes.

The website supports:

- Mobile phones
- Tablets
- Laptops
- Desktop monitors

Bootstrap's grid system and custom media queries were used to optimise layouts and improve usability on smaller screens.


### Typography

The Inter typeface was selected because it offers excellent readability across all screen sizes and provides a modern user interface appearance.
